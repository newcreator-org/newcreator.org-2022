# 先生・学校向けAI情報サブページ実装レポート

## プロジェクト概要

newcreator.orgに先生・学校向けのAI関連情報を掲載するサブページを作成し、多様なコンテンツから流入できるマーケティング施策を実装しました。

## 実装内容

### 1. ページ構成

以下のページを新規作成しました。

#### メインランディングページ
- **URL**: `/for-educators/`
- **概要**: 先生・学校向けサービスの総合案内ページ
- **主要セクション**:
  - ヒーローセクション（キャッチコピーと主要サービス紹介）
  - サービス詳細（出張研修、AI導入支援、プライベートGPT）

  - 導入事例へのリンク
  - 実践ガイドへのリンク
  - FAQへのリンク
  - お問い合わせCTA

#### 実践ガイド一覧・詳細ページ
- **URL**: `/for-educators/guides/`
- **概要**: 教育現場でのAI活用に関する実践的なガイド記事
- **作成記事数**: 6本
  1. 授業でのChatGPT活用基礎
  2. AI活用による授業準備の効率化
  3. 生徒に教えるAIリテラシー教育
  4. 学校でAIを安全に使うためのセキュリティガイドライン
  5. 効果的な教員向けAI研修プログラムの設計方法
  6. 2026年の教育AI活用トレンドと学校が今すべきこと

#### 導入事例一覧・詳細ページ

  - 導入について

- **質問数**: 20問以上

### 2. サイト全体への統合

#### ヘッダーナビゲーション
- グローバルナビゲーションに「先生・学校の方へ」リンクを追加
- デスクトップ版とモバイル版の両方に対応

#### トップページCTAセクション
- サービスセクション直後に先生・学校向けCTAセクションを追加
- 3つの主要サービスをカード形式で紹介
- 目立つブルーグラデーション背景で視認性を確保

### 3. 技術実装

#### Markdown処理関数の追加
- `libs/markdown.ts`に以下の関数を追加:
  - `getAllEducatorGuides()` - 実践ガイド一覧取得
  - `getEducatorGuideById(id)` - ガイド詳細取得
  - `getAllEducatorCaseStudies()` - 導入事例一覧取得
  - `getEducatorCaseStudyById(id)` - 事例詳細取得

#### ページコンポーネント
- Next.js 12のPages Routerを使用
- TypeScript + Tailwind CSSで実装
- 既存のコンポーネント（Header, Footer, ScrollFadeIn）を活用
- レスポンシブデザイン対応

#### コンテンツ管理
- Markdownファイルでコンテンツを管理
- フロントマターでメタデータを定義
- 静的サイト生成（SSG）で高速なページ表示を実現

## コンテンツ戦略

### SEOキーワード設計

以下のキーワードを意識してコンテンツを作成しました。

**メインキーワード**:
- 学校 AI 導入
- 教員 生成AI 研修
- 教育現場 ChatGPT
- プライベートGPT 学校
- AI リテラシー教育

**ロングテールキーワード**:
- 授業でChatGPTを使う方法
- 学校でAIを安全に使うには
- 教員向けAI研修プログラム
- 生成AIセキュリティガイドライン
- 教育AI活用事例

### コンテンツの特徴

**1. 実践的で具体的**
- 抽象的な説明ではなく、すぐに使える具体的な方法を提示
- ステップバイステップの手順を記載
- 実際の活用シーンを想定した内容

**2. 信頼性の担保**
- 実在する学校の事例を参考に作成
- 文部科学省のガイドラインに言及
- データや実績を具体的に記載

**3. AI感の排除**
- 絵文字や装飾記号を使用しない
- 落ち着いたトーンで記述
- 教育現場に寄り添った表現

**4. 多様な流入経路**
- 初心者向けから上級者向けまで幅広いコンテンツ
- 導入前、導入中、導入後の各段階に対応
- 検索意図に応じた記事構成

## 技術的な注意事項

### ビルドとデプロイ

本実装はNext.js 12のPages Routerを使用しています。デプロイ前に以下を確認してください。

```bash
# 依存関係のインストール
pnpm install

# ビルド
pnpm build

# ローカルで確認
pnpm dev
```

### 既知の課題

**1. Markdownのレンダリング**
- 現在はシンプルなHTML変換を使用
- より高度なMarkdown機能が必要な場合は、react-markdownの導入を検討

**2. 画像の最適化**
- Next.js Imageコンポーネントを活用
- 適切なサイズと形式での画像提供が必要

**3. パフォーマンス**
- 静的サイト生成により高速
- 大量のコンテンツ追加時はビルド時間に注意
